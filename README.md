# Fundamentals — SQL Basics

This folder contains the SQL exercises completed during the Fundamentals section of the course.  
These practice queries introduce essential concepts using the DVD Rental database.

## Concepts Covered

- Filtering records using `WHERE`
- Searching text patterns with `LIKE`
- Retrieving unique values using `DISTINCT`
- Counting records with `COUNT()`
- Filtering ranges with `BETWEEN`
- Sorting results with `ORDER BY`
- Grouping data using `GROUP BY`
- Filtering grouped results with `HAVING`
- Calculating aggregates (`SUM`, `AVG`, `MIN`, `MAX`)

## Files Included

- **fundamentals.sql** — Basic filtering, text search, distinct values  
- **group_by_and_having.sql** — Grouped analysis and aggregate filtering  
- **ASSESSMENT TEST 1.sql** — Small final test combining key fundamentals

These exercises form the foundation for the next modules, including joins, advanced functions, and subqueries.
